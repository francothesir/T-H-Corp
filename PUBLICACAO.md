# T&H Corp — publicação

O site pode ser publicado pelo GitHub Pages no domínio `thcorp.com.br` após ativar **Settings → Pages → Deploy from a branch → main / (root)** e configurar os DNS da Hostinger.

O modelo 3D original fica dividido em `assets/mask/part-00.b64` até `part-12.b64`, recombinado no navegador por `assets/site.js`, sem alterar a aparência do site. Os arquivos originais estão no Google Drive.
